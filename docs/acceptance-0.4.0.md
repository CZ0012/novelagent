# 0.4.0 工作台验收

本版将连接恢复与作者工作台一起交付，没有单独发布 0.3.2。测试使用隔离的本地工作区、合成作品、账号与模型，不使用作者的桌面窗口、小说或套餐额度。

| 作者操作 | 验证结果 |
| --- | --- |
| 空工作台发送第一句话 | 创建作品和会话，正文与聊天分区可独立操作。第二次新建会话时输入框为空。 |
| 查找旧会话或原话 | 可以按标题和消息检索；跳转使用项目、会话和消息 ID，包括当前上下文窗口之外的内容。 |
| 手动重命名 | 名称重启后保留；迟到的自动标题不能覆盖手改。达到同一连接可用模型的条件时只触发一次标题请求。 |
| 新会话接续构思 | 项目记忆附作者原消息。模型可保留待定灵感；人工修改和撤回覆盖原记录，相关内容按项目和语言筛选。 |
| 回到既有稿件 | 作品、场景、工作区、会话与阅读比例按本地范围恢复。取消离开保留未保存编辑，放弃本次编辑保留原保存稿。 |
| 后端晚于界面启动 | 模型设置与账号信息独立恢复。显式保存连接并用于主 Agent 后，下一次模拟主对话使用实际选中的模型。 |
| 窄屏与英文界面 | 合成浏览器检查覆盖 390、980 和 1440 像素宽度，检查编辑器、聊天和面板操作。 |

此处的模型交互验证覆盖请求的内容、去向与次数。真实 ChatGPT 登录路径和小说写作样本分别记录于 [0.3.1 登录验收](acceptance-0.3.1.md) 和 [0.3.0 作者协作验收](acceptance-0.3.0.md)。
