# 0.3.1 ChatGPT 连接与 Writer 交接验收

Windows 桌面及本机 Windows 后端使用同一套官方 OAuth 流程。真人验收通过系统浏览器登录并授权，在隔离的空作品工作区发现可用模型，再经保存的任务连接向官方 Responses 端点发送一次短文本并收到预期回复。验收没有发送小说正文。其余验证使用合成账号、合成草稿与模拟服务，不额外消耗用户套餐。

| 验证对象 | 验证范围 |
| --- | --- |
| 账号与授权 | 动态注册、状态与 nonce、PKCE、身份签名校验、套餐授权、注册复用、刷新互斥和退出。Windows 当前用户保护存储位于作品目录之外。 |
| 模型调用 | 模型发现和流式 Responses 使用官方地址。拒绝、额度不足、连接中断、缺失完成事件以及账号失效都向调用方报告。 |
| 写作交接 | Main 用真实配置清单选择会话 Writer，实际生成沿用该连接。断连、模型切换和过时指纹不会改用另一连接。选择动作本身不调用模型，讨论也不会携带写作授权。 |
| 公开内容 | 软件源码、说明和三项 Windows 更新资产分别核对；测试数据与操作日志留在忽略目录。 |

官方注册文档说明了开源客户端动态注册的流程。用户在 OpenAI 的授权界面可能会看到未经验证的应用提示。[官方登录说明](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)

离线完整回归通过 1,484 项 Python 测试（另跳过一项）和 320 项 Web 测试。浏览器回归覆盖登录状态与设置异步加载，以及主 Agent 选择 Writer 后从普通场景写作入口继承连接。历史 v0.3.0 的小说样本与本次连接验证分别记录。
