# 0.4.1 主 Agent 请求验收

使用空作品和合成中文首句验证完整主会话 HTTP 入口。0.4.0 的套餐连接已获得 HTTP 200，但流以错误事件结束：开启 JSON-object 输出时，发送给 Responses 的输入消息缺少 JSON 标记，只有顶层系统说明包含格式约束。此前纯文本连通性测试没有覆盖此条件。

修复后的真实请求先由主 Agent 调用项目结构查询，再生成中文答复，两次模型请求均收到完成事件，工作台会话接口返回 200。没有发送作者的真实消息、正文或账号标识到发布记录。

离线回归覆盖原错误、成功的工具循环、多轮历史、角色推演与选文隔离、纯文本和关闭 JSON 模式的请求、重新打开会话的错误提示及失败后不自动重复计费调用。

0.4.1 正式发布后，公开更新清单、签名和安装器均可匿名下载，SHA-256 与验签候选包相符。Windows x64 安装器为 37,039,500 字节，SHA-256 为 `d53904e8950541baa145c1deaa63d2c81dae51b44866a9b0ec8a0726fdf6e7ca`。完整回归中 Python 1,518 项通过、1 项跳过，Web 331 项通过。解包后的独立后端报告 0.4.1。[GitHub Release](https://github.com/CZ0012/novelagent/releases/tag/v0.4.1)
