## 已实现的能力

- 中文优先的目录、正文、Agent 工作台；讨论、规划、协同写作、审阅入口；精确选区、Ctrl+S/Ctrl+Enter、原稿差异与采用保护。
- 项目级 Agent 风格画像，包含视角、节奏、措辞、对白、禁用表达和评估要求；适用于不同配置模型，保持项目语言及正典优先。
- 分层蓝图、章场预算、跨卷因果和伏笔；完整规划任务在非正典分支运行，限定调用/修订次数，保存断点，最终整书清单经人工接受后显式应用。
- 精确版本的语义审查，引用原文与正典证据，区分场景/规划范围，按正文、风格和正典指纹判断过期。裸引用清单不能冒充完整规划接受语义检查。
- 自然正文事实提案与人工审阅；生死、伤势、位置和归属通过不可变时点断言维护，支持乱序写作。历史错误由明确修正候选纠正，旧证据保留。
- 保护项目的生成正文先进入提案；旧直接生成路径不能绕过审查。作者手动保存仍可使用，状态变化始终需要明确审阅。

### 作者简报的审查依据与过期报告

真实验收反复遇到一种无效报告：模型引用了作者简报中的摘要长度要求，却只提供target引用，没有合同要求的style引用。规划审查现在从冻结的原始请求或已核验父蓝图取得作者简报，作为独立style来源；不会把任意生成正文里的指令提升为风格权威。引用清单优先提供style/canon条目，完整目标原文仍保留，未知引用、错误类型和请求标识继续严格校验。

该显式来源参与报告指纹，旧规划报告需重新审查，不能修补旧响应使其通过。整书完成前还核验各阶段报告及缓存整书报告的通过状态和新鲜度；失效时暂停，不产生新调用或待接受清单。人工应用闸门继续复核。全量回归1038通过、1跳过，独立15项专项覆盖过期/非通过报告的零调用阻断、历史保持及有效整书的接受/应用路径。此更新已包含在上文`f563579`候选包，打包源码与隔离运行再次核验通过。

后续真实审查还曾要求蓝图立即包含全部100章/200场景，混淆了整体目标与当前阶段。PLAN提示现明确使用已有阶段元数据：蓝图检查世界、规则、人物及卷章场预算；扩章检查当前批次及与前文/蓝图的相容性；最终整书才要求完整网格与全部精确引用。真实缺口、上游矛盾、证明链及引用校验均保留，普通场景提示未改变。55项针对性检查与独立11项检查通过；这不是模型正确率证明，也未重放旧报告。该后续提示修改需包含在下一次候选包构建中。

另一份真实报告因额外`status_reason`字段被原有严格解析器拒绝。审查请求现同时携带由既有模型定义导出的机器可读输出schema，明确规范引用或已登记短编号两种格式、精确请求标识及禁止额外字段。接受格式、解析器、证据、新鲜度和原文覆盖均未放宽；旧响应仍无效。schema只是给模型的格式说明，服务端仍独立验证。全量1048通过、1跳过，独立44项检查通过；尚需新的真实请求验证格式可靠性，不能宣称模型再不会出错。

### Flash 真实验收中间记录（未通过）

截至2026-10-25本次检查，共用账本记录29/80次请求，按峰值价格保守结算约3.575808元；这不是最终账单。主力为官方 `deepseek-flash`，当前启用显式 `thinking=enabled`、`reasoning_effort=low`，每次请求在费用预留之前公开其包括推理余量的输出上限。隐藏推理文本未保存，仅记录 token/字符数及完成状态。

当前低档推理任务完成五卷蓝图和第一批五章提案，但被审查挡在第一批：压力峰值与七分钟记录空白的时间有真实冲突；证据链藏匿安排、人物知识基线与部分伏笔阶段区分仍须修订。一份审查报告含有未引用风格依据的风格建议，系统按既定合同判为无法确认，没有删掉该问题后冒充通过。所有生成仍在隔离提案分支，图谱未自动变化。

同时查明章节生成请求缺少每卷总章数，可能使模型在首五章提前完成二十章的高潮。正在补充明确的整卷进度信息，并通过显式回退蓝图、保留旧产物和失效下游的路径修复。上述结果不能作为100章/200场景真实验收通过的证据。

后续截至36次已完成调用的检查：保守结算约4.861012元，图谱未自动变化。修订后的蓝图获得一份仅含建议的通过报告；首批章节仍发现何昀行动缺少知情依据，并遇到模型复制错修改前原文的问题。新修订接口允许模型仅给出完整字段替换，服务端从固定版本构造精确原值；旧错误格式仍严格拒绝，不重放或改造旧失败响应。原始创作要求现贯穿后续扩章和审查，默认模型等待时间调整为300秒并保留显式覆盖值。
