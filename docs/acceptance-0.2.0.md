# StoryGraph Agent 0.2.0 候选版本验收记录

日期：2026-10-25（Asia/Shanghai）。当前为本地源码构建候选版本，未发布 GitHub Release，也未替换作者安装或工作区。

**整体目标尚未宣布验收通过。** 核心实现、离线规模测试、真实五卷蓝图复核和本地包检查已完成；完整真实模型的100章/200场景独立规划及后续正文风格/连续性抽样仍待本轮批量调用预算确认。

## 已实现的能力

- 中文优先的目录、正文、Agent 工作台；讨论、规划、协同写作、审阅入口；精确选区、Ctrl+S/Ctrl+Enter、原稿差异与采用保护。
- 项目级 Agent 风格画像，包含视角、节奏、措辞、对白、禁用表达和评估要求；适用于不同配置模型，保持项目语言及正典优先。
- 分层蓝图、章场预算、跨卷因果和伏笔；完整规划任务在非正典分支运行，限定调用/修订次数，保存断点，最终整书清单经人工接受后显式应用。
- 精确版本的语义审查，引用原文与正典证据，区分场景/规划范围，按正文、风格和正典指纹判断过期。裸引用清单不能冒充完整规划接受语义检查。
- 自然正文事实提案与人工审阅；生死、伤势、位置和归属通过不可变时点断言维护，支持乱序写作。历史错误由明确修正候选纠正，旧证据保留。
- 保护项目的生成正文先进入提案；旧直接生成路径不能绕过审查。作者手动保存仍可使用，状态变化始终需要明确审阅。

## 小规模真实模型证据

使用作者授权的 DeepSeek 官方连接，在忽略的隔离目录运行。共记录10次实际模型请求；本地保留135,290输入 tokens、62,249输出 tokens 的用量记录。模型和思考模式明确记录，未自动更换模型或重发未知调用。

真实生成了五卷、500,000字符规划预算的世界观与框架蓝图。独立审读和语义模型发现时间顺序、证据链及容量说明问题，经过修订和精确段落修改，最后一份 DeepSeek Pro 复核为 `pass`、0条问题。严格验证也拒绝了截断输出、额外字段、错误原文定位；未把无效输出当成成功。

定点修改仅接受允许路径下的完整字段或唯一精确片段，保留其余文本；不作模糊匹配。一个已经付费产生并本地保留的有效修改结果在明确的无操作/唯一片段语义下重新验证，没有为重放再次付费。该证据不是完整100章生成的替代，也不是任意底层模型都能保持相同文学风格的证明。
