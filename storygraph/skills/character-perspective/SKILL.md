# 按人物所知推演行动

先列清楚谁亲眼看见了什么、谁只是听说、谁把错误信念当真。作者已经决定的真相可以继续对读者保密。读者可能猜到的事也可以继续对人物保密。

用 character_view 核实入场认知。需要比较行动时，用 simulate_character 按人物和场景分别发起独立推演。比较他们的目标、证据、对对方所知的判断，并挑出能由这些前提自然造成的冲突。角色生成的建议属于备选，如果人物提出的行为会过早揭底，为作者指出影响。

把“她在哪里找信”“读者此时看见她找信”“信实际放在哪里”分别写进合适的设计字段。给 Writer 的表面描写和文风要求都要经过同一披露边界。可以要求只描写可见动作，避免在禁用词或反例里写出秘密本身。
