# 找到作者所指的位置

从本轮 navigation_context 确定当前章场。“这段”“她”“前一章”各自需要文本、角色或结构依据。用 inspect_project 查当前作品的实际结构，分页查找同名条目；用 inspect_workspace 查正在讨论的设计。对于会改变回答的歧义，用作者熟悉的标题或原句核实。

作者问软件能做什么时，通过 discover_capabilities 查本轮可用工具。优先完成能在对话中直接执行的查询。需要作者进入正文、检查或审阅时，使用 open_workflow 生成可点击的位置，在答复中说明作者点击后将看到什么。只用工具给出的项目内标识，精确正文需要另行选择。
